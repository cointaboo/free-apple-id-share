## 二、正确登录方式（关键，做错会锁机）

**只从 App Store 登录，绝对不要在「设置」里登录。**

```
❌ 错误做法：设置 → 顶部 Apple ID → 退出登录 → 输入共享账号
   → 这会让整台设备绑定到一个陌生人共享的账号上
   → 对方一改密码，你的设备可能被锁，照片通讯录有泄露风险

✅ 正确做法：App Store → 右上角头像 → 退出登录 → 输入共享账号
   → 只影响 App Store 这一个入口，不影响设备的 iCloud
```

**下载完成后立刻退回自己的 Apple ID**，已下载的 App 照常能开。

## 三、为什么这里不放账号明文

这个仓库曾经差点放明文，后来改主意了，三个理由：

1. **放明文的仓库会被爬虫批量抓取**，脚本拿去做自动化登录，账号当天就被苹果锁掉，所有人都用不了。多个同类仓库都踩过这个坑，后来都改成只放打码版。
2. **明文账号 = 明文凭据**，仓库一旦被 fork 或镜像，就再也收不回来了。
3. 账号是每天变的，仓库里的静态明文几小时后就失效，留着只是误导。

所以本仓库的做法是：**讲方法 + 给入口**，实时账号到下面的站点看。

## 五、常见问题

**Q：提示「此 Apple ID 尚未在 App Store 使用过」怎么办？**
A：正常提示，直接点「检查」或继续，不需要填付款信息。要求填付款方式时选「无」。

**Q：提示 Apple ID 已被锁定 / 已停用？**
A：这个号被苹果风控了，换列表里另一个。共享号被锁是常态，别去申诉（不是你的号）。

**Q：下载提示需要验证手机号？**
A：换一个号，或者稍后再试。

**Q：能登几台设备？**
A：技术上不限，但同一账号登录设备越多越快被锁。下完就退。

**Q：共享号下载的 App，退出账号后还能用吗？**
A：能。App 已经装到设备上了，跟账号解绑后照常运行。但**更新时需要重新登录**同一个账号。

**Q：共享号能充值 / 订阅吗？**
A：不要。多人共用的号上绑支付方式，风险由你承担，而且对方随时能改密码。

**Q：买独享号值不值？**
A：看你用途。只用一次下载 → 共享号。要长期用、要订阅 ChatGPT Plus / 小火箭、要收验证邮件 → 独享号，能改密能绑自己邮箱，不会因为别人乱登被锁。

## 六、安全红线

1. **不要在「设置」里登录共享账号**（会锁机）

4. **下载完立刻退出**，不要长期挂着
5. **别用共享号收重要邮件**（邮件对所有人可见）

## 七、自己注册外区账号（彻底解决）

如果你不想受共享号的气，可以自己注册一个美区 Apple ID，永久归你：

1. 准备一个没注册过 Apple ID 的邮箱（Gmail / Outlook 都行）
2. 浏览器打开 `appleid.apple.com`，地区选美国，正常填信息
3. 地址随便填一个真实的美国地址（网上能查到公开的商场地址）
4. 付款方式选「无」
5. 注册完成后在 App Store 登录，地区就是美区

难点在**注册时的手机验证**和**IP 环境**——用国内 IP 注册美区号，大概率被要求验证手机号或直接失败。这一步要么用干净的海外网络，要么直接买现成的。
